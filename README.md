# Moonlanders

Low-poly 3D игра за браузър и телефон. Копаеш ресурси, строиш и ъпгрейдваш машини, свързваш ги с конвейери, зареждаш ракетата и отлиташ към следващата планета: **Луната → Марс → Европа**.

## Как се играе

- **Движение:** плъзни пръст където и да е по екрана (телефон) или използвай WASD / стрелките (компютър).
- **Копаене:** застани в кръга около находище и ресурсите сами влизат в раницата.
- **Машини:** застани до машина. Тя сама взима нужните суровини от раницата ти и ти дава готовата продукция.
- **Строене и ъпгрейди:** застани върху цветна площадка и ресурсите се плащат сами, бройка по бройка.
  - синя: нова машина
  - зелена: ъпгрейд на машина. Ниво 2 включва конвейер, който пълни машината автоматично.
  - лилава: ъпгрейд на скафандъра (раница, скорост, кислород)
- **Кислород:** пълни се само под купола. Ако свърши, връщаш се в базата, но губиш всичко, което носиш.
- **Рециклатор:** червеният кръг до ракетата изхвърля ненужните неща от раницата.
- **Ракета:** зареди я с исканите ресурси и натисни **Launch**.

Жълтата стрелка на земята и целта горе вляво винаги показват следващата стъпка. Прогресът се записва автоматично в браузъра.

## Разработка

Изисква Node.js 22.12 или по-нов.

```bash
npm install
npm run dev        # локален сървър с hot reload
npm test           # unit тестове + автоматично минаване на цялата кампания
npm run typecheck
npm run build      # production build в dist/
```

### Структура

| Папка | Съдържание |
| --- | --- |
| `src/config` | Ресурси, баланс и дефиниции на планетите. Нова планета = нов файл в `config/planets`. |
| `src/core` | Чиста игрова логика без рендериране: симулация, машини, площадки, кислород, цели, записване. Покрита с тестове. |
| `src/render` | Three.js сцена, low-poly модели, надписи в света. |
| `src/input` | Клавиатура и плаващ виртуален джойстик. |
| `src/ui` | HUD, диалози, иконки. |
| `src/audio` | Звукови ефекти, генерирани с Web Audio (без аудио файлове). |
| `src/game` | Главният цикъл, който свързва всичко. |

## Публикуване (GitHub Pages)

Workflow-ът в `.github/workflows/deploy.yml` пуска тестовете и build-а при всеки push. Публикува само от основния (default) branch.

Еднократна настройка: **Settings → Pages → Build and deployment → Source: GitHub Actions**. След това играта е на `https://<user>.github.io/moonlanders/`.
