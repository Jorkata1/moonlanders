# Starhop

3D браузърна игра за CrazyGames: ракетата ти катастрофира на Луната, копаеш материали с лазерна дрелка, строиш машини и роботи от тях и поправяш скоковия двигател, за да отлетиш.

**Историята:** скоковият двигател изгаря, ракетата пада зад хребета, а ти се спасяваш с капсула, от която се разгъва малка база. Пари няма: всичко се строи с материали от планетата.

- **Въглерод и лунна глина** се копаят от самото начало.
- **Желязна руда** пада от небето в полето си, след като построиш топилнята (руда → метални плочи 1:1).
- **Helium X** е зад хребета. Минната сонда пробива стената, а кристалите копае само играчът. Рафинерията прави от 2 Helium X една хелиева клетка.
- **Работната маса** поръчва по една постройка: появява се холограма на мястото ѝ и материалите се носят там от теб или от товарния дрон.
- **Роботите** само копаят и трупат до 100 материала до гаража си, включват се и се изключват и имат по 3 нива. **Дронът** е единственият, който пренася: купчините и плочите до холограмата, рудата до топилнята. **Станцията за скафандъра** продава дрелка, раница (15 → 25 → 35), кислород и скорост.
- **Лазерът** е гъвкав лъч: загрява 2 секунди (тънък и син), после се заключва (дебел и оранжев) и следва дрелката.
- **Марс и ледената луна** предстоят.

Има спокойна синтезирана музика (бутон с нота горе вдясно) и вибрация на телефон (включва се и изключва от паузата).

Направена е с **Three.js + TypeScript**. Целият билд е един HTML файл, без картинки и звукови файлове: текстурите се рисуват в кода, а звуците се синтезират.

## Първо пускане

Нужен е Node.js 18 или по-нов.

```bash
npm install
npm run dev
```

После отвори http://localhost:5173. Всеки път, когато запишеш файл, играта се билдва наново, а ти презареждаш страницата.

## Команди

| Команда | Какво прави |
|---|---|
| `npm run dev` | Сървър за разработка с автоматичен билд |
| `npm test` | Бот изиграва Луната до излитане и проверява записа (старите записи започват наново), поръчките, роботите, дрона и сондата |
| `npm run typecheck` | Проверка на типовете |
| `npm run build` | Финален билд в `dist/` |
| `npm run package` | Билд и zip за качване в CrazyGames (`dist/starhop-crazygames.zip`) |
| `npm run check` | Всичко горе наведнъж; пускай го преди качване |

## Работа с Claude Code

Отвори папката и пусни `claude`. Файлът `CLAUDE.md` обяснява архитектурата, къде какво се променя и правилата за кода. Claude Code го чете автоматично.

Примерни задачи:
- „Добави Марс като втора планета“
- „Направи третото ниво на роботите по-евтино“
- „Добави нова постройка в работната маса“

## Къде какво е

- **Цени, скорости, баланс:** `src/config.ts` и `src/planets/moon.ts`
- **Ред на планетите:** `src/planets/index.ts`
- **Логика на играта:** `src/sim/`. Тя е чиста и се тества без браузър.
- **3D графика:** `src/view/`
- **Интерфейс:** `src/hud.ts`, `src/page.html` и стиловете в `src/styles/` (телефонният изглед е в `compact.css`)
- **Интро и туториал:** `src/intro.ts` и `src/tutorial.ts`
- **Музика и звуци:** `src/music.ts` и `src/audio.ts`
- **CrazyGames SDK:** `src/platform.ts`

## Качване в CrazyGames

1. `npm run check`
2. `npm run package`
3. Качи `dist/starhop-crazygames.zip` (или само `dist/crazygames/index.html`) в developer portal.
